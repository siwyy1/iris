# Iris Classification Model

This is an educational project whose goal was to build a model that classifies
Iris species based on flower measurements. The model was created using
scikit-learn and the K-Nearest Neighbors (KNN) algorithm.

While working on this project, I used another notebook as a learning resource.
It helped me understand the complete end-to-end process: loading and exploring
the data, creating visualizations, training and evaluating the model, saving
the trained model, and presenting it through a simple Streamlit application.

The project was created primarily to gain practical experience with machine
learning fundamentals and to learn how a trained model can be used in an
application.
